User Guide

How to Use Indexer PM System

  1. Register / Sign In — Create an account with NIM (student) or name (lecturer), then sign in.
  2. Home dashboard — View PM due alerts, machine counts, and quick links.
  3. Technical Documentation — Read indexer maintenance procedures (from ESEC manual).
  4. PM Schedule — Fill Excel layout (click cells: 12 → 26 → 52), toggle Active/Inactive on floor layout, mark PM done on WW list.
  5. Checklist — Select machine WB001–WB100 and complete preventive tasks.
  6. History — Review who did what and when.
  7. Export — Download CSV (Excel) or print PDF report from Home.
  8. Profile — Edit name, email, photo, password; switch language EN/ID from the header.
  9. Master — Admin can view all registered users (online/local).
